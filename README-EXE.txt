PIXELFORGE STUDIO — сборка EXE через GitHub Actions (без установки Node.js на ваш ПК)

1. Создайте аккаунт на https://github.com/ (если его ещё нет).
2. Нажмите New repository, задайте имя PixelForgeStudio и создайте репозиторий.
3. Загрузите ВСЕ файлы и папку .github из этого архива в корень репозитория.
   Убедитесь, что файл .github/workflows/build-windows.yml загружен именно по этому пути.
4. Откройте вкладку Actions репозитория.
5. Если GitHub попросит, нажмите "I understand my workflows, go ahead and enable them".
6. Выберите "Build PixelForge Studio for Windows" и нажмите Run workflow.
7. Дождитесь зелёной галочки. Откройте завершённый запуск и внизу страницы скачайте artifact
   PixelForge-Studio-Windows-Installer.
8. Распакуйте скачанный ZIP — внутри будет установщик PixelForge-Studio-Setup-1.0.0.exe.

Примечание: это публичный или приватный репозиторий на ваш выбор. Для бесплатного аккаунта
GitHub Actions обычно достаточно для такой сборки; действуют текущие лимиты GitHub.

AI-помощник требует собственного совместимого API URL, модели и API-ключа. Не добавляйте
API-ключ в репозиторий или исходники. Вводите его только в самой программе на своём компьютере.

Это оригинальный независимый проект, не связанный с Adobe. Версия пока базовая:
PSD, маски, полноценные AI-операции и продвинутые инструменты ещё не реализованы.
